# rh-facility-media

Visuels publics des posts LinkedIn de RH Facility, servis par GitHub Pages pour que Metricool les récupère.

- `linkedin/` : images publiées (`AAAA-MM-JJ-sujet.png`), URL `https://celine06800.github.io/rh-facility-media/linkedin/<fichier>`
- `outils/linkedin/` : charte, pages HTML de chaque semaine (`semaines/AAAA-MM-JJ/`, avec `textes.md`) et script de rendu

Aucune donnée client ni donnée RH ici : uniquement des visuels de communication.
